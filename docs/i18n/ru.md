# Настройка Brother DS-940DW на Synology DSM 7

[Руководство на английском](../synology.md) · [README проекта](../../README.md)

Включите сканер и вставьте лист. Программа на NAS сохранит обе стороны в одном PDF. Файлы можно направлять в общую папку SMB, в существующий Paperless-ngx или в новый экземпляр Paperless-ngx, запущенный вместе с приёмником.

## 1. Подготовьте сканер и NAS

1. Установите **Container Manager** из **Центра пакетов**. Драйвер этого проекта требует NAS с архитектурой x86-64. Команда `uname -m` должна вывести `x86_64`.
2. Подключите сканер к домашней сети в режиме Wi-Fi и зарезервируйте его IPv4-адрес на маршрутизаторе. NAS должен иметь доступ к сканеру по локальной сети. В проверенной установке использовались TCP 54921 и UDP 161.
3. Создайте в **File Station** папку `/volume1/docker/ds-940-paperless-scanner`. Скопируйте в неё содержимое репозитория, включая `Dockerfile`, `compose.yaml`, `ds940/` и `.env.example`.
4. При первой установке создайте `work` и `consume`, затем скопируйте шаблон в `.env`.

```sh
cd /volume1/docker/ds-940-paperless-scanner
mkdir -p work consume
cp .env.example .env
chmod 600 .env
```

Укажите адрес сканера в `SCANNER_IP`. В `SCAN_UID` и `SCAN_GID` задайте идентификаторы пользователя и группы с правом записи в оба каталога. В сеансе SSH их можно узнать командами `id -u` и `id -g`. Храните `.env` локально на NAS.

## 2. Сохранение в общую папку или существующий Paperless

Для SMB укажите в `SCAN_OUTPUT_DIR` путь к общей папке на NAS. Для Paperless найдите в Container Manager **путь на хосте**, подключённый к `/usr/src/paperless/consume`, и запишите его в `SCAN_OUTPUT_DIR`. Оба контейнера должны иметь доступ к одной папке. Если Paperless не замечает новые файлы на сетевом ресурсе, задайте в его окружении `PAPERLESS_CONSUMER_POLLING_INTERVAL=15`.

В Container Manager выберите **Проект → Создать**, укажите папку с исходниками и загрузите `compose.yaml`. Соберите образ и запустите проект. Если мастер не читает `.env`, запустите приёмник через SSH.

```sh
cd /volume1/docker/ds-940-paperless-scanner
sudo docker compose -p ds-940-paperless-scanner -f compose.yaml config --quiet
sudo docker compose -p ds-940-paperless-scanner -f compose.yaml up -d --build scanner
```

## 3. Запуск нового Paperless-ngx

Создайте `export` и проверьте права записи выбранного пользователя и группы в `work`, `consume` и `export`. В локальном `.env` задайте два разных случайных значения для `POSTGRES_PASSWORD` и `PAPERLESS_SECRET_KEY`. Каждое можно сгенерировать командой `openssl rand -hex 32`. Для доступа с другого устройства укажите LAN-адрес NAS в `PAPERLESS_BIND_IP`. Порт по умолчанию — 8010.

```sh
cd /volume1/docker/ds-940-paperless-scanner
mkdir -p export
sudo docker compose -p ds-940-paperless-scanner -f compose.yaml -f compose.paperless.yaml config --quiet
sudo docker compose -p ds-940-paperless-scanner -f compose.yaml -f compose.paperless.yaml up -d --build
```

Откройте Paperless по настроенному адресу и создайте первого администратора. Команды выбранного варианта можно один раз выполнить от имени `root` через пользовательский скрипт в **Планировщике заданий** DSM. Сохраните строку с `cd` и уберите `sudo`.

## 4. Проверка первого скана

1. Включите Brother и дождитесь `Ready for paper` в журнале контейнера `scanner`. В файле `work/auto-status.json` при готовности появится `waiting_for_paper`.
2. Отметьте лицевую и оборотную стороны тестового листа. Вставьте его лицевой стороной вверх. Дождитесь полного выхода листа перед подачей следующего.
3. Откройте PDF в общей папке или в Paperless и проверьте обе стороны. Дождитесь завершения импорта и OCR. Выключите сканер после серии.

Профиль по умолчанию — `SCAN_PAPER_SIZE=a4`. Режим `auto` определяет размер, а `legal` использует фиксированную область длиной около 355,6 мм. Полное сканирование длинного чека в режиме Legal ещё предстоит проверить на устройстве. Для бумаги длиннее A4 закройте верхнюю направляющую выхода. После смены профиля выполните `docker compose up -d scanner` с тем же именем проекта и теми же файлами `-f`.

## Обновление приёмника

Скопируйте файлы новой версии в `/volume1/docker/ds-940-paperless-scanner`, заменив старые. В репозитории нет `.env`, `work`, `consume` и `export`, поэтому ваши настройки и сканы сохранятся. Затем пересоберите приёмник по SSH с тем же именем проекта и теми же файлами `-f`, что и при установке. Если вы используете Paperless-ngx из этого проекта, добавьте `-f compose.paperless.yaml`.

```sh
cd /volume1/docker/ds-940-paperless-scanner
sudo docker compose -p ds-940-paperless-scanner -f compose.yaml up -d --build scanner
```

## Устранение неполадок

Большинства проблем можно избежать, соблюдая три правила: включайте сканер только непосредственно перед сканированием, никогда не нажимайте на нём кнопку сканирования (сканирование начинается, когда вы вставляете лист, а сканер сам его затягивает) и выключайте сканер после каждой серии.

- Если после нажатия кнопки сканирования мигает жёлтый восклицательный знак и сканер не отвечает, удерживайте кнопку питания несколько секунд и дождитесь полного выключения. Контейнеры оставьте запущенными. Снова включите сканер, дождитесь Wi-Fi и `Ready for paper`, затем вставьте лист ещё раз.
- Если вставленный лист не запускает сканирование после того, как сканер долго был включён без работы, его пул сетевых соединений переполнен. Выключите и снова включите сканер, дождитесь `Ready for paper` и вставьте лист ещё раз.
- При `scanner_offline` проверьте Wi-Fi, зарезервированный адрес и доступность сканера с NAS.
- При `scanner_busy` или `-NG 401` закройте другие программы сканирования. Дождитесь повторной попытки или выключите и снова включите Brother.
- При `paper_blocked` откройте верхнюю крышку, осторожно извлеките лист и закройте крышку.
- Если документа нет в Paperless, проверьте путь, права и журнал. В `work/spool` состояние `ready` означает ожидание передачи, а `forwarded` подтверждает запись PDF в целевую папку. Архивируйте старые задания после проверки импорта и сохранения нужных копий.
